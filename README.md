# Mossgrove

A mobile-friendly, original monster music game.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Unzip these files and upload every file directly to the repository root. Keep `index.html` at the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Open the Pages URL GitHub shows after it finishes publishing.

The game saves progress in the current browser on the current device. This flat package includes the page, game scripts, artwork, app icons, manifest, and service worker.
